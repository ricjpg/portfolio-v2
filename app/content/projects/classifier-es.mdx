# Clasificador de perros y gatos en tiempo real

![Classifier Banner](../../../public/images/classifier.png)

# Descripción del proyecto

Este proyecto abordó la necesidad de automatizar la identificación visual de animales mediante inteligencia artificial. En contextos como refugios de animales, vigilancia inteligente o herramientas educativas, es necesario distinguir rápidamente si una imagen o un video en vivo corresponde a un perro o a un gato. La clasificación manual resulta lenta, propensa a errores y difícil de escalar cuando se trabaja con grandes volúmenes de datos.

# Solución propuesta

Se desarrolló un sistema de clasificación en tiempo real basado en redes neuronales convolucionales (CNN), entrenadas con TensorFlow y Python. La aplicación puede procesar imágenes estáticas y entrada de cámara en vivo, identificando en cada cuadro si el sujeto es un perro o un gato con una latencia mínima.

El flujo del proyecto incluyó la preparación del conjunto de datos, el entrenamiento del modelo, la validación de resultados y la exportación del modelo para su integración en una interfaz web ligera desarrollada con JavaScript, HTML y CSS. Gracias a esta integración, la predicción se ejecuta directamente desde el navegador, sin requerir un proceso de inferencia complejo en el backend.

# Tecnología utilizada

- Python para la preparación de datos, entrenamiento y exportación del modelo
- TensorFlow para la construcción y entrenamiento de la CNN
- Redes neuronales convolucionales para la extracción de características visuales
- HTML y CSS para la interfaz de usuario
- JavaScript para la interacción con la cámara y la experiencia web

# Funcionalidades principales

- Clasificación en tiempo real desde webcam
- Interfaz ligera, responsive y fácil de usar
- Modelo personalizado entrenado para dos clases
- Integración completa entre machine learning e interacción del usuario

# Resultados y valor del proyecto

El desarrollo demuestra cómo un modelo de inteligencia artificial puede trasladarse de un entorno experimental a una solución práctica y accesible para usuarios finales. Además, permite visualizar de manera directa la aplicación de TensorFlow y Python en sistemas de inferencia en tiempo real, reforzando la conexión entre investigación aplicada y productos digitales interactivos.
