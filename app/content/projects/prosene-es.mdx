# Contexto del problema

El Programa de Servicios a Estudiantes con Necesidades Especiales (PROSENE) de la Universidad Nacional Autónoma de Honduras (UNAH) enfrentaba dificultades importantes en la gestión y seguimiento de solicitudes. Los estudiantes debían acudir físicamente a las oficinas para presentar sus requerimientos, lo que representaba una barrera para quienes tenían limitaciones de movilidad u otras necesidades de accesibilidad. Este proceso manual generaba retrasos, duplicidad de información y una baja trazabilidad de las solicitudes.

# Solución desarrollada

Se diseñó una aplicación web que permite a los estudiantes enviar solicitudes de apoyo desde cualquier lugar, sin necesidad de acudir de forma presencial. La plataforma ofrece a los funcionarios de PROSENE una visión centralizada de las peticiones y facilita la gestión de cada caso.

Entre las capacidades principales se encuentran:

- Registro de solicitudes estudiantiles en línea
- Seguimiento del estado y historial de cada caso
- Comunicación más ágil entre estudiantes y personal administrativo
- Mejora de accesibilidad y reducción de fricción operativa
- Centralización de la información para una respuesta más eficiente

La solución se construyó pensando en un enfoque inclusivo, que reduzca la dependencia de procesos presenciales y fortalezca la atención personalizada.

# Tecnologías utilizadas

- Frontend: Vue.js, HTML y CSS
- Backend: Python y FastAPI
- Autenticación: JWT
- Base de datos: PostgreSQL en AWS RDS
- Despliegue: Vercel para el frontend y AWS RDS para la base de datos

# Impacto y resultados

- Mejora significativa en la accesibilidad para estudiantes con necesidades especiales
- Reducción del tiempo de respuesta y atención
- Automatización de procesos antes realizados de forma manual
- Implementación de autenticación y control de roles
- Desarrollo full stack con despliegue real y enfoque en UX

# Valor del proyecto

Este proyecto surgió como una iniciativa universitaria orientada a resolver un problema real dentro del campus. Representa una clara muestra de transformación digital con enfoque en inclusión, accesibilidad y mejora de los servicios institucionales.
