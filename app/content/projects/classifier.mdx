# Dog and Cat Classifier in Real Time

![Classifier Banner](../../../public/images/classifier.png)

# Problem Statement

In many scenarios, such as animal shelters, smart surveillance systems, and educational tools, automatically identifying whether an animal is a dog or a cat from an image or live webcam feed can be highly valuable. However, manual labeling is time-consuming, inefficient, and prone to human error, especially when dealing with large datasets or real-time video streams.

# Solution

To address this challenge, we developed a real-time image classification system capable of distinguishing between dogs and cats using Convolutional Neural Networks (CNNs) and TensorFlow. The system processes static images and live webcam input, classifying each frame as either a dog or a cat with minimal latency.

Using Python and TensorFlow, we trained a CNN on a labeled dataset of dog and cat images. The model learns spatial patterns and feature hierarchies from the images, allowing it to detect subtle visual differences between the two classes. Once trained, the model was exported and incorporated into a lightweight web application built with JavaScript, HTML, and CSS, enabling real-time predictions directly from the browser.

# Technologies Used

- Python for model training, preprocessing, and export
- TensorFlow for building and training the CNN
- Convolutional Neural Networks for image feature extraction and classification
- HTML and CSS for building the user interface
- JavaScript for frontend interaction and webcam integration

# Key Features

- Real-time classification using a webcam
- Lightweight and responsive web interface
- Custom-trained CNN model
- End-to-end integration between machine learning and browser-based interaction

# Notes

This project demonstrates how machine learning models can be deployed in interactive environments, bridging the gap between AI research and user-facing applications. It also highlights the practical use of TensorFlow and Python for real-time inference in web-based systems.
