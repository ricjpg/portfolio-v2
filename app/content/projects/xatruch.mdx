# Problemática

La aerolínea Xatruch enfrentaba dificultades operativas relacionadas con la gestión manual de sus vuelos nacionales e internacionales. El control de itinerarios, destinos, aeronaves, pasajeros y horarios se realizaba mediante procesos poco eficientes, localizados y difíciles de escalar. Esto generaba retrasos, duplicidad de información, errores humanos y una baja trazabilidad de las operaciones.

# Solución

Se desarrolló una plataforma web robusta y escalable para centralizar la administración de la operación aérea. La solución permitió gestionar vuelos, rutas, horarios, pasajeros, reservas y asignación de aeronaves desde un único sistema.

Entre las principales funcionalidades se incluyeron:

- Registro y administración de vuelos nacionales e internacionales
- Control de rutas, frecuencias y estados operativos
- Gestión de aeronaves por trayecto
- Registro de pasajeros y validación de reservas
- Diferenciación de roles para administradores y agentes de vuelo

El sistema fue diseñado con un enfoque modular, seguro y adaptable, listo para integrarse con futuras funcionalidades como pagos digitales, check-in presencial o gestión de equipaje.

# Tecnologías utilizadas

- Java para la lógica principal del backend
- Spring Framework para la arquitectura y la seguridad del sistema
- Hibernate y JPA para la persistencia de datos
- PHP y Laravel para módulos complementarios
- MySQL como base de datos relacional
- HTML, CSS y JavaScript para la construcción de la interfaz de usuario

# Resultados

- Reducción del tiempo operativo en la gestión de vuelos
- Mayor precisión y consistencia en la información
- Mejora en la trazabilidad documental y operativa
- Base sólida para futuras extensiones del sistema

# Valor del proyecto

Este proyecto representa una solución completa de análisis, diseño e implementación en un entorno realista. Además de consolidar conocimientos de ingeniería de software, demuestra cómo la automatización de procesos de negocio puede mejorar la eficiencia y la calidad operativa en sectores altamente regulados como el transporte aéreo.
